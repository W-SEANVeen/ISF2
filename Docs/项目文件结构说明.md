# 《孤城》VR 游戏项目 — 文件结构说明

> 本文档说明项目各主要目录及文件的内容与作用，方便快速了解项目全貌。
> 以下所有路径均相对于项目根目录（即 Unity 项目文件夹）。

---

## 一、顶层目录

| 目录/文件 | 作用 |
|-----------|------|
| **Assets/** | **核心资源目录**。所有游戏资源（场景、脚本、模型、材质、音效、UI 等）都在这里，是开发时主要工作目录。 |
| **ProjectSettings/** | Unity 项目全局设置（图形、输入、物理、播放器等）。 |
| **Packages/** | 包依赖清单，记录项目引用的官方包和第三方包。 |
| **PICO-Unity-Integration-SDK-release_3.1.0/** | PICO VR 官方 SDK（3.1.0），含平台 API、空间音频、企业功能等，VR 功能基础依赖。 |

---

## 二、Assets/ 子目录

### Scenes/
- Unity 场景文件（.unity），游戏世界容器
- 主场景：`Scene2_city_v2.unity`（城市战场主关卡）

### Script/
- C# 脚本目录，按功能子文件夹分类（详见第三节）

### Prefab/
- 预制体模板，可复用的游戏对象
- 包含：箭矢、云朵、弩、UI 面板、火焰等

### model/
- 3D 模型文件（.fbx），项目的模型资产主体
- 包含角色（士兵、马匹）、建筑（塔楼、城门、房屋）、武器（弩、箭、旗帜）、地形、云梯等

### Animation/ 与 animator/
- **Animation/**：动画剪辑（.anim），如死士攻击、骑兵死亡等动作片段
- **animator/**：Animator Controller（.controller），管理动画状态机和过渡

### material/、Materials/、shader/
- **material/**：基础材质（颜色、贴图属性）
- **Materials/**：雪花粒子材质
- **shader/**：Shader Graph + 手写 shader，实现**水墨描边（PropOutline）**、地形、飘旗、远山等视觉效果，是水墨画风格的核心

### Textures/
- 纹理贴图（.png/.jpg），水墨画风的素材库
- 包含：水墨笔触、宣纸背景、山峦贴图、雪花粒子、墨迹纹理等

### Audio/
- 音效资源，SFX 子目录存放战场音效：
  - 战争号角、拉弓射箭、破空声、鼓声、游戏号角回声

### Fonts/
- 中文字体：HarmonyOS Sans SC（鸿蒙）、庞门正道粗书体
- TextMesh Pro SDF 配置

### VFX/
- Visual Effect Graph 粒子效果（.vfx），如下雪特效

### Resources/
- 可通过 `Resources.Load()` 运行时加载的资源

### ScriptableObject/
- ScriptableObject 配置，如音效集合配置（AudioCollectionSO）

### XR/ 与 XRI/
- **XR/**：PICO XR Loader 与运行设置
- **XRI/**：XR Interaction Toolkit 编辑器设置

### TextMesh Pro/
- TMP 字体、着色器、精灵、样式表，实现高品质文字渲染

### Plugins/
- 原生插件，如 Android 平台的 AndroidManifest

### pic/
- UI 与背景图片：按钮背景、远山剪影、城墙贴图等

### Settings/
- 项目自定义设置资源

### TutorialInfo/
- URP 模板自带的教程资源与 Readme 脚本

### rig/
- 角色骨骼绑定资源

## 三、Script/ 脚本详解

所有 C# 脚本位于 `Assets/Script/`，按模块分子目录：

### managers/ — 管理器模块

| 文件名 | 作用 |
|--------|------|
| `GameManager.cs` | 全局游戏状态管理（进行中/胜利/失败） |
| `SceneFlowManager.cs` | 场景流程与切换控制 |
| `BattleDirector.cs` | 战场事件导演，驱动攻城时间线 |
| `SiegeManager.cs` | 攻城战管理器，控制攻城梯等事件 |
| `EventManager.cs` | 全局事件发布/订阅，模块间解耦 |
| `AudioManager.cs` | BGM 与 SFX 播放、切换、音量管理 |
| `PlayerHealth.cs` | 玩家生命值、扣血、死亡判定 |
| `HornPlayer.cs` | 战争号角氛围音效触发 |
| `BootLoader.cs` | 场景启动初始化 |
| `SceneChanger.cs` | 异步场景加载与过渡 |
| `GameEndUIManager.cs` | 胜利/失败界面 UI |
| `MenuUIManager.cs` | 主菜单 UI |
| `XRUIManager.cs` | VR 交互界面（射线点击等） |

### armymanage/ — 军队管理模块

| 文件名 | 作用 |
|--------|------|
| `SquadCommander.cs` | 小队指挥：移动、攻击、阵型 |
| `ArmyMover.cs` | 编队寻路与前进控制 |
| `EnemyAssault.cs` | 敌方冲锋行为逻辑 |
| `EnemyHorse.cs` | 骑兵移动与骑乘战斗 |
| `EnemyRandomizer.cs` | 敌人外观与行为随机化 |
| `ArmyBeanScatterer.cs` | 军队散布逻辑，使分布更自然 |
| `ArrowFlight.cs` | 箭矢弹道与命中检测 |
| `ArrowRainVolley.cs` | 箭雨齐射（多箭并发） |
| `SiegeLadder.cs` | 攻城梯展开与搭靠控制 |
| `PorterRetreat.cs` | 搬运工撤离行为 |
| `MicroMotion.cs` | 角色细微动作（呼吸、摇摆） |

### obj/ — 交互对象模块

| 文件名 | 作用 |
|--------|------|
| `CrossbowShoot.cs` | 弩射击与装填逻辑 |
| `ArmyAdvance.cs` | 军队推进触发器 |
| `Igniter.cs` | 火焰/火箭点火效果 |
| `RickIgniteController.cs` | 火箭点燃与发射流程控制 |

### VR/ — VR 交互模块

| 文件名 | 作用 |
|--------|------|
| `ResetXROrigin.cs` | 重置 VR 空间位置 |
| `StickyGrabInteractable.cs` | 粘性抓取（物体吸附在手） |
| `VRFaceHUD.cs` | 面向 HUD，UI 跟随视线 |

### tools/ — 工具模块

| 文件名 | 作用 |
|--------|------|
| `GridGenerator.cs` | 场景辅助网格生成 |
| `AudioCollectionSO.cs` | ScriptableObject 音效集合定义 |

### 根目录脚本

| 文件名 | 作用 |
|--------|------|
| `EnemyCharge.cs` | 单体敌人冲锋 |
| `TestArrowShooter.cs` | 箭矢发射调试脚本 |
| `TorchFireController.cs` | 火炬火焰效果 |
| `WeaponTrailController.cs` | 武器拖尾刀光轨迹 |
| `control_ball.cs` | 球体控制（调试/UI 辅助） |
